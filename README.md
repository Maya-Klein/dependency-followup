# Dependency Follow-up Assistant

כלי למעקב אחר נושאים שממתינים לגורמים אחרים (ספק, עמית, רשות). לכל נושא יש מועד יעד, והקוד מחשב ממנו כמה ימים נותרו ומסמן את הנושא באחת מחמש דרגות דחיפות. הממשק בעברית, מימין לשמאל.

הפרויקט בנוי בשלבים קטנים. כרגע מומש **שלב 1 (שער 1)**: שמירת מועד והצגתו בצבע לפי הימים שנותרו. האפיון ב-[`docs/spec.md`](docs/spec.md) והתוכנית המלאה ב-[`docs/plan.md`](docs/plan.md).

## דרגות הדחיפות

הספים מוגדרים פעם אחת, ב-`app/core/deadlines.py`. הימים הם ימים קלנדריים לפי תאריך בלבד, בשעון ישראל (`Asia/Jerusalem`).

| ימים שנותרו | דרגה | תווית |
|---|---|---|
| 6 ומעלה | `far` | רחוק |
| 2–5 | `approaching` | מתקרב |
| 1 | `tomorrow` | מחר |
| 0 | `today` | היום |
| פחות מ-0 | `overdue` | באיחור |

## ארכיטקטורה

שלוש שכבות עם תלות חד-כיוונית, כך שאפשר להחליף את הממשק בלי לגעת בלוגיקה:

```
web  ──►  core      (לוגיקה טהורה, בלי Flask ובלי DB)
 │
 └─────►  storage   (SQLAlchemy Core, SQLite)
```

| רכיב | קבצים | תפקיד |
|---|---|---|
| `app/core/` | `deadlines.py` | חישוב ימים שנותרו (`days_remaining`), דרגת הדחיפות (`urgency_level`), הניסוח העברי (`days_text`) ו"היום" בשעון ישראל (`today_in_israel`). פונקציות טהורות שמקבלות `today` כפרמטר, ולכן הבדיקות דטרמיניסטיות. |
| `app/storage/` | `db.py`, `repository.py` | הגדרת טבלת `topics` ופונקציות `add_topic` ו-`list_topics`. החיבור נקבע ב-`DATABASE_URL` (ברירת מחדל `sqlite:///data/app.db`). כותרת ריקה או ארוכה מ-200 תווים נדחית. |
| `app/web/` | `__init__.py`, `routes.py`, `templates/`, `static/` | אפליקציית Flask: `create_app()`, נתיבי `GET /` ו-`POST /`, ותבניות Jinja2 עם escaping אוטומטי. |
| `run.py` | | הפעלת השרת המקומי על `127.0.0.1:5000`. |
| `tests/` | | pytest לכל שלוש השכבות. |

## זרימת הנתונים

**הוספת נושא (`POST /`):**
1. הטופס שולח כותרת ותאריך.
2. ה-route בודק את התאריך ואת אורך הכותרת. `add_topic` מסיר רווחים בקצוות ודוחה כותרת ריקה.
3. הנושא נשמר בטבלת `topics`.
4. הדפדפן מופנה ל-`GET /` (redirect 303). בשגיאה חוזר הדף עם קוד 400 והודעה בעברית, וההזנה נשמרת.

**הצגת הרשימה (`GET /`):**
1. `list_topics` שולף את הנושאים ממוינים לפי מועד.
2. לכל נושא, `days_remaining` מחשב את הימים שנותרו מול `today_in_israel()`, ו-`urgency_level` קובע את הדרגה.
3. התבנית מציגה כותרת, תאריך, ניסוח הימים ותווית, עם מחלקת CSS `level-<דרגה>`. הצבע לא נושא את המידע לבדו, כי יש גם תווית טקסט.

הדחיפות מחושבת בקוד בלבד.

## התקנה

דרוש Python 3.9 ומעלה (נבדק רק עם 3.14).

```
git clone https://github.com/Maya-Klein/dependency-followup.git
cd dependency-followup
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

בלינוקס ובמק משתמשים ב-`.venv/bin/python` במקום `.venv\Scripts\python`. החבילה `tzdata` ברשימה כי ב-Windows אין מאגר אזורי זמן מובנה.

## הרצה

```
.venv\Scripts\python run.py
```

האפליקציה זמינה ב-http://127.0.0.1:5000. קובץ ה-DB נשמר ב-`data/app.db` (לא עולה לגיט). אפשר לשנות אותו עם המשתנה `DATABASE_URL`.

## בדיקות

```
.venv\Scripts\python -m pytest
```

הבדיקות מכסות את ערכי הקצה של הדרגות, מעברי חודש ושנה, אזור זמן סביב חצות, שמירה ושליפה מחיבור חדש, כותרת ריקה או ארוכה מדי, תאריך לא תקין וכותרת עם קוד HTML שמוצגת כטקסט.
